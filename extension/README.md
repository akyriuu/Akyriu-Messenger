# Ryuto Messenger — Chrome Extension

Chrome Manifest V3 side-panel client for the Ryuto Messenger NestJS backend. The production backend is configured by default; no third-party messaging service is used.

## Build and install

From this directory:

```bash
npm install
npm run build
```

Then open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select this `extension/` folder. The `dist/` folder is generated by the build, including the service worker bundle. After changes, run `npm run build` and click Reload on the extension card.

The extension defaults to `https://ryuto-messenger.onrender.com`. To use another server, set `VITE_API_URL` and `VITE_SOCKET_URL` before building, then add that server to `host_permissions` in `manifest.json`.

The extension uses the same username/password authentication, friend-request routes, message-history route, and Socket.IO events as the web frontend.

## Notes

- JWT is stored in `chrome.storage.local` to persist the login.
- The backend's Socket.IO gateway authenticates extension connections using `auth: { token }`.
- This initial version does not include notifications or an unread-message badge.
